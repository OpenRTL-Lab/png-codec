# 测试结果与边界

本说明报告硬件1.2.1实际测过什么、数值怎样解释，以及不能据此推导哪些结论。
历史硬件测试与后来执行的可移植命令检查分别记录，不能当作同一轮新测试。

[English](results.md)

## 测量定义

E 表示编码器，D 表示解码器。功能回归、性能测量和离线文件检查是不同集合，
不能相加并称为不同的硬件测试图像。任务是从命令握手到完成握手的一幅完整图像；
所有通道在时钟沿 valid、ready 同时有效时传输。

宽 W、高 H、通道数 C、位深 d 对应原始行长 `R = ceil(W*C*d/8)`，图像长 `B = R*H`。
计入每行末尾不满有效位的完整字节，不计行滤波类型字节、PNG 封装或元数据。
原统计脚本均用周期差，不额外加一拍：

- 冷启动完整延迟 `L = c - a`，a 为命令接收，c 为完成接收；冷启动单独测量。
- 连续间隔 `II = (c32 - c1)/31`，c1～c32 为同实例 32 个相同任务的完成握手，
  任务间无复位或人为插空。这是完成间隔，不是流水线发射速率。
- 持续原始吞吐 `T = 31*B/(c32-c1) = B/II`，下表采用此口径，
  不用 B/L 或整批 32 图像窗口速率，也不合计并行实例。

正常集合的项目目标并非 PNG 标准要求：`B/L >= 19/20`、`B/II >= 19/20`，
即至少 0.95 原始字节/周期。实际精确判定为 `20*B >= 19*L`、
`20*31*B >= 19*(c32-c1)`；不能把允许周期向上取整，误收边界失败。

首图像延迟 F 是命令接收到首次承载图像内容的输出握手的周期差。
E 解析实际 PNG，定位重建第一个图像样本字节所需的最后一个压缩字节，
不把行滤波类型字节算图像，并对承载该字节的输出拍计时；D 取首个原始样本输出拍。
两者均不是首文件头拍。设 PLTE/tRNS 合计长度为 M，正常集合每个冷启动和连续任务均检查：
E 为 `F <= M + R + 64`；D 为 `F <= M + K`，测试的 STORED/FIXED/DYNAMIC 流模式
对应 K=128/256/4096 周期。这是按配置规定的启动延迟上限，独立于吞吐；
在这些测试公式中，M、R 的每个字节数值对应一周期的允许量。
六个解码压力项则单独报告 0.89 原始字节/周期建议，不取代正常门槛。

来源固定于[来源清单](../SOURCE_MANIFEST.json)。发布整理只增声明及可移植接线，不改硬件算法；
精确去声明注释恢复原产品/测试/C参考/时钟包装正文。一个报告标志适配和新增工具单列，不称纯注释。
该标志记录是否编译可选产品断言绑定模块；本仓未分发这些额外检查模块，但编译测试台断言。
标志只改报告，不改编解码实现或预期图像数据。

## 功能测试

负向对照是故意破坏期望值或输入，要求检查器拒绝结果，证明错误检测有效，不是又一次成功解码。
原功能为152个编码/228个解码完整PNG、37个编码/66个解码协议错误恢复任务，以及复位/背压/容量和像素/元数据/状态/tag负向对照、
alpha/边界及双向8192²Gray1（1位灰度），不外推全部最大格式/纹理。
418项RGBA16（四通道、每通道16位）检查是对实际文件的离线语义检查，不是新增RTL任务。
声明31/32个距离码条目（HDIST+1）的RFC合法边界测试与固定zlib拒绝互通分开，
保留距离符号仍非法；libpng1.6.59依赖zlib1.3.2，不算两独立算法。

## 正常性能与压力测试

正常主集合为170个编码/255个解码配置，(170+255)*33=14025任务，每配置一次冷启动加32次连续任务，
逐项满足精确19/20及首图像预算。
下表分别选择两个方向持续原始吞吐最低的配置，不是用同一幅图像进行双向排名。
L、II、F 及其预算均以周期计；吞吐为 B/II，单位是原始字节/周期。
输入一旦就绪即供数，输出一旦有效即接收，不插入外部停顿；测量覆盖完整编解码任务，
不是单独压缩核心的速率。

| --- | --- | --- | ---: | ---: | ---: | ---: | ---: |
| 编码 | 1024×512，索引1位，渐变 | None / STORED | 65,536 | 66,876 | 66,877 | 0.979948263230 | 92 / 199 |
| 解码 | 256×256，索引8位，渐变 | None / DYNAMIC | 65,536 | 68,230 | 68,231 | 0.960501824684 | 1,774 / 5,119 |

该比较不是全部170个编码配置；本仓不捆绑旧基线产物，公开命令本身不能重现该历史比较。

## 特定目标综合

完整条件表、互不重叠的级数分布、面积分类及 SRAM 数量见
[综合结果](synthesis-summary.zh-CN.md)。以下保留本结果文档所需的结论和计数定义。

WNS为最差setup裕量，TNS为负setup裕量总和。Z/ZN为本项目计数：每端点选最差setup数据路径，
仅数数据路径输出pin叶名严格为Z或ZN者，不计时钟树；分子为计数严格>50的端点数，
分母为全量统计端点数，不是所有单元类型计数、最大RTL深度或所有可能时序路径。
综合固定500MHz/2ns/.2ns uncertainty/1ns IO/SSG0.81V−40°C，E WNS+.000149965ns、
严格>50为0/12138；D+.000034332ns、36/30295（0.118831490345%），两者TNS/负Setup端点0。
两门槛WNS≥0且严格>50比例≤5%均通过。解码最大Z/ZN计数58不是失败：门槛限制超过50的
端点比例，并非限制单个路径最大值。hold不作本次验收。
该目标的存储约定包括真实同步RAM延迟/使能/同址行为，不分发受限报告/网表/物理宏/商业工具；
不声称布局布线签核、板测、硅后、物理芯片面积/功耗、通用最高频率Fmax或商业同条件匹配。
