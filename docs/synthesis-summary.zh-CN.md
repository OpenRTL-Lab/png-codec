# 综合结果

PNG 1.2.1 的完整编码器与解码器采用 Design Compiler NXT，在 TSMC 28 nm HPC+、
SSG 0.81 V／−40 °C、500 MHz 和 10% setup 时钟不确定度下通过 setup。
编码最差 setup 裕量为 +0.000149965 ns，解码为 +0.000034332 ns；两者负 setup
裕量总和及违例端点数均为零。按下文定义的 Z/ZN 输出引脚计数规则，已报告路径中，
编码 100%、解码 99.8713% 的级数严格小于 50。

[English](synthesis-summary.md)

## 综合对象与条件

| 项目 | 条件 |
| --- | --- |
| 产品 | PNG Codec 1.2.1，编码与解码独立综合 |
| 完整顶层 | `PngEncoder`、`PngDecoder`，不含验证环境 |
| 软件 | Synopsys Design Compiler NXT X-2025.06-SP3 |
| 标准单元 | TSMC 28 nm HPC+，7-track |
| 库工艺角 | SSG，0.81 V，−40 °C |
| 时钟 | 2.000 ns 周期，500 MHz |
| Setup 时钟不确定度 | 0.200 ns，占周期 10% |
| 输入／输出最大延迟 | 各 1.000 ns |
| 输出负载 | 0.020，单位采用目标库的电容单位 |
| 最大数据转换时间／扇出 | 0.250 ns／32 |
| 存储映射 | 同步一读一写 SRAM；编码 68／解码 96 个物理宏 |
| 面积口径 | 含已映射 SRAM 的综合 cell 面积，不是 die 面积 |

以上是归档运行条件，不是对其他库的工作点保证。标准单元与 SRAM 采用选定的 SSG
视图；输出负载保留库单位，本摘要不声称已独立核定其到 pF 的换算。
时钟不确定度预留 setup 预算，不改变编解码协议。

公开 RTL 表达通用存储行为。集成时须逐块保持读延迟、使能及同址同时读写语义，
不能把所有数组统一替换为一种假定宏；部分小查找表保留为逻辑。
详见 [架构说明](architecture.zh-CN.md)。

## Setup 与逻辑级数

WNS 是最小 setup 裕量，TNS 是负 setup 裕量之和。每个已约束端点选一条最差 max
数据路径，只统计数据路径上叶引脚名严格等于 `Z` 或 `ZN` 的输出引脚，每个计一级。
不按 net、文本行、clock-to-Q 或时钟树计数。这依赖所用库，不是通用门级深度。

| 指标 | 编码 | 解码 |
| --- | ---: | ---: |
| Setup | 通过 | 通过 |
| WNS，ns | +0.000149965 | +0.000034332 |
| TNS，ns | 0 | 0 |
| 负 setup 裕量端点 | 0 | 0 |
| 已约束且报告的端点 | 12,138 | 30,295 |
| 级数严格 <50 | 12,138（100%） | 30,256（99.8713%） |
| 恰为 50 | 0 | 3 |
| 严格 >50 | 0（0%） | 36（0.1188%） |
| 最大计数 | 44，一条路径 | 58，一条路径 |

三个级数区间互不重叠。统计包含内部到内部、内部到输出、输入到内部，编码分别
11,227／260／651 条，解码 29,324／420／551 条。SRAM 端点按完整引脚名区分。
归档审计曾逐一核对完整报告与导出 timing-points 的精确 Z/ZN 引脚序列，
不是只比较舍入后的裕量字符串。

项目通过条件为 WNS ≥0，且计数**严格大于 50** 的端点比例不超过 5%，精确判定
`20*N_above50 <= N_total`。恰为 50 不计入大于 50；解码最大 58 因此不违反该比例
门槛。以上不证明 hold 或 recovery/removal 闭合，也不是枚举全部可能路径。

工艺/SRAM 库、原始商业工具脚本、约束、报告、映射网表或快照。
